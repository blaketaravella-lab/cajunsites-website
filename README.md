# CajunSites

Marketing site for CajunSites.com.

## Stack
- Astro
- Static output for Cloudflare
- No client framework dependency

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

Cloudflare build command: `npm run build`
Output directory: `dist`

## Pre-launch items
- Connect the Get Started form to the selected production form/Worker endpoint.
- Replace draft Privacy Policy and Terms with reviewed final language.
- Connect production analytics if desired.
- Configure the custom domain in Cloudflare after deployment.
